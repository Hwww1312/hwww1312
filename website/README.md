# Cambodian Food Stars — Immersive 3D Website

Cinematic scroll-driven homepage for **Cambodian Food Stars**, a Cambodian restaurant at 14 Buckingham Ave, Springvale VIC 3171.

## Quick start

```bash
cd website
npm install
npm run dev
```

## What you get

- Six-chapter scroll story with one persistent WebGL canvas
- Procedural placeholder plate textured with real restaurant photography
- GSAP ScrollTrigger timeline (`src/data/storyConfig.ts`)
- About, Contact (reserve + message), Privacy
- Reduced-motion and no-WebGL fallbacks
- Lacquer green + lemongrass brand system (from the existing design brief)

## Facts policy

Nothing factual is invented. Name, address, phone, closing time, busiest hours, rating, review count, and verbatim reviews come from the Google Business listing. Dish notes describe what is visible in the restaurant’s own photographs.
