# Cambodian Food Stars

Immersive 3D storytelling website for Cambodian Food Stars (Springvale).

## Active app

The production Next.js experience lives in **`website/`**.

```bash
cd website
npm install
npm run dev
```

See `website/README.md`, `website/IMPLEMENTATION.md`, and `website/docs/`.

## Legacy reference

The `app/` folder retains the earlier one-page Higgsfield source (parallax + hero film concept), brand photography sources, and design brief. Brand facts and assets were migrated into the Next.js app; do not deploy `app/` as the new site.

`source-photos/` holds ungraded restaurant photographs. `tools/` contains the legacy hero-film / OG render scripts.
